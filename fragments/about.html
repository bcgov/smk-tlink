The Truck Route Planner (TRP) is intended to be an interactive, easy to understand trip-planning application for goods movement in Metro Vancouver. It improves on existing regional way-finding and trip planning tools, which was identified as an implementation priority in the Regional Goods Movement Strategy (RGMS).

It is intended to augment, rather than replace existing regional and municipal truck route maps and trip planning tools and includes multiple layers, such as truck parking facilities, card locks, and height clearances.

A key feature of the TRP is a route query function which generates potential routes that comply with municipal truck route bylaws. This feature allows users to plan bylaw-compliant routes throughout the region quickly and easily. Users simply enter vehicle dimensions, a starting point, and destination to generate a potential route that factors in information such as height and weight restrictions.

The TRP was developed in partnership between TransLink and the Province with input from municipalities and industry.

This application is intended to be used as a pre-trip planner. Do not operate a vehicle while using this application.
